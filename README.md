# 🦆 可愛插畫鴨鴨檔案刪除助手 - Desktop Duck Deleter

這是一個超級治癒又充滿趣味的 Windows 桌面互動應用！當你想刪除電腦上的檔案時，不再是冰冷的系統提示，而是可以召喚出一隻圓滾滾、呆萌的小黃鴨，搖搖擺擺地走到檔案面前，歪頭確認後一腳將檔案連同垃圾桶一起化作漫天飛舞的可愛羽毛與星星，最後戴上帥氣墨鏡開心飛走！

## ✨ 核心亮點

- 🎯 **萌系鎖定準星**：溫暖的奶油插畫背景與鴨鴨萌系瞄準準星，治癒感滿滿。
- 🦆 **超萌鴨鴨全套逐幀動效**：包括搖擺走路、歪頭指認、飛踢打擊、羽毛爆破、墨鏡勝利 Pose、螺旋槳竹蜻蜓起飛等全套精緻插畫動畫。
- 🎵 **超可愛專屬鴨鴨音效與配樂**：
  - 🐥 **鴨鴨對話萌音**：清脆可愛的「呱呱～！嘎嘎～！✨」鴨鴨語音。
  - 💥 **Q 彈魔法爆破音**：漫畫風「啵！(BOING-POP!)」彈跳與漫天閃亮星光音效。
  - 🎶 **歡樂小黃鴨進行曲 BGM**：木琴 (Marimba) 與輕快撥弦結合的歡樂治癒背景音樂。
- 🖱️ **智慧右鍵選單整合**：程式執行時自動在 Windows 右鍵選單註冊「召喚可愛鴨鴨吃掉」選項（支援檔案與資料夾）。
- 🚀 **指哪吃哪**：在任意資料夾或桌面右擊檔案召喚鴨鴨，或直接手動點擊螢幕任意檔案，使命必達。

## 📦 如何使用

1. **直接執行**：執行 `python main.py`，螢幕會出現治癒插畫瞄準介面，點擊你想刪除的檔案，欣賞小鴨鴨的表演！
2. **右鍵召喚**：在桌面上或任意資料夾中，右鍵點擊你想刪除的檔案，選擇 **「召喚可愛鴨鴨吃掉」**。

> ⚠️ **安全提醒**：程式使用 `send2trash`（安全移至資源回收筒）而非永久粉碎，如果不小心手滑，隨時可以從資源回收筒輕鬆還原。

## 🛠️ 開發與依賴 (Developer Guide)

### 1. 安裝依賴
```bash
pip install -r requirements.txt
```

### 2. 本地執行測試
```bash
# 進入瞄準模式
python main.py

# 指定刪除特定檔案
python main.py "C:\path\to\your\file.txt"
```

### 3. 一鍵打包 (PyInstaller)
```bash
pyinstaller --noconfirm --onefile --windowed --name DuckDeleter --add-data "assets;assets" --hidden-import send2trash main.py
```

